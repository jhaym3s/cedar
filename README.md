# Prerequisites
Make sure you have the following installed before cloning the project
- Flutter
- X-CODE
- Android Studio

# Set up 
git clone the repo https://github.com/jhaym3s/cedar.git

install flutter dependencies using `flutter pub get`

then run `flutter run`
